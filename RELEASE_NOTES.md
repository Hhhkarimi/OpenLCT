# OpenLCT v1.0.0 Release Notes

## Logistics Control Tower Prototype

OpenLCT v1.0.0 provides a unified operational view for FMCG logistics:

- Supplier to warehouse visibility
- Warehouse to store distribution monitoring
- Store to customer last-mile simulation

## Product Modules

- Command Center
- War Room
- Analytics
- Inbound
- Distribution
- Last Mile

## Architecture

Next.js + TypeScript + Tailwind CSS

Designed for free deployment using Vercel.
